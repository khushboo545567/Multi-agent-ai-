#  Multi-Agent AI Platform

**A powerful AI platform that intelligently routes user requests to specialized AI agents — no manual agent selection required.**

Just type your prompt. The system detects your intent and automatically invokes the right agent — chat, search, image generation, code generation, PDF generation, or PowerPoint generation — to get the job done.

---

##  Overview

Traditional AI applications require users to manually choose different AI models or tools for each task. **Multi-Agent AI Platform** eliminates that complexity by automatically detecting the user's intent and routing the request to the most suitable AI agent using **LangGraph**. This creates a seamless, unified AI experience where users simply describe what they need, and the platform intelligently handles the rest.

---

##  Intelligent Agent Routing

| User Prompt | Selected Agent |
|--------------|----------------|
| "Explain React Hooks" | 💬 Chat Agent |
| "Latest AI news" | 🌐 Search Agent |
| "Generate a presentation on Machine Learning" | 📊 PPT Generator |
| "Create a PDF report about Climate Change" | 📄 PDF Generator |
| "Build a Todo App using React" | 💻 Coding Agent |
| "Generate an image of a futuristic city" | 🖼️ Image Generation Agent |

No dropdowns. No manual model selection. Just describe what you want, and the platform automatically routes your request to the right AI agent.

##  Features

- 🔐 **Google OAuth Authentication** — secure one-click sign-in
- 💬 **AI Chat Assistant** — context-aware conversational responses
- 🌐 **AI Web Search** — real-time information retrieval
- 🖼️ **AI Image Generation** — text-to-image generation from prompts
- 💻 **AI Code Generation** — generates applications, components, APIs, and utilities
- 📄 **PDF Generation** — automatically creates professional PDF documents
- 📊 **PowerPoint Generation** — generates presentation slides from prompts
- 🧠 **Automatic Agent Selection** — intelligent LangGraph-based routing
- ⚡ **Fast & Scalable Architecture** — Redis caching and modular backend services
- ☁️ **Cloud Image Storage** — Cloudinary integration for generated images
- 📱 **Responsive User Interface** — optimized across desktop and mobile devices
